# RefVault — SEO & GEO Referral Website (GitHub Pages Ready)

This folder contains the complete static website in English, engineered for Google SEO (USA, UK, Global) and AI Generative Engine Optimization (GEO).

## How to Deploy on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload the contents of this ZIP folder directly to the root of your repository (`index.html`, `css/`, `js/`, `offers/`, `blog/`, `sitemap.xml`, `robots.txt`, `llms.txt`).
3. Go to **Settings > Pages**, select `Deploy from a branch` (`main` / `root`), and click **Save**.
4. Once you have your live domain or GitHub Pages URL, replace `https://refvault.github.io` in `sitemap.xml` and `robots.txt` with your final domain name.
